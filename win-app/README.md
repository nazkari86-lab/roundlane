# Roundlane 3.0 для Windows

Самостоятельная программа со встроенным Chromium и публичными компонентами SEB, собранными из исходников. Отдельный Safe Exam Browser не устанавливается и не запускается.

## Сборка

1. На Mac/хосте: `python3 scripts/prepare-native-windows.py`.
2. На Windows с Visual Studio Build Tools и .NET Framework 4.8/WPF: `scripts/build-native-windows.ps1 -Source <checkout> -Output <output>`.
3. Передайте содержимое созданного `runtime` в `win-app/dist/runtime`.
4. Закрытый ключ сборки задаётся ROUNDLANE_SIGNING_KEY; для своего ключа обновите core/runtime_key.go. Ключ не публикуйте.
5. `win-app/build.sh`: Go core tests, x64 форма и hub, архив полного изменённого исходного кода, NSIS установщик. Нужны Go, ImageMagick, makensis и проверенные Microsoft redistributables.

## Установка

`Roundlane 3.0 Setup.exe` устанавливает одну программу в Program Files и собственную службу Roundlane. Для установки службы нужен администратор ОС; обычному участнику повышенные права не нужны. В меню «Пуск» и на рабочем столе появляется Roundlane; отдельно доступна утилита восстановления Windows. Приложение автоматически после перезагрузки не запускается; служба запускается для восстановления ограничений после сбоя.

До старта проверяются хеши встроенных файлов, наличие работающей службы именно этой установки, профиль выхода и локальный порт. Неполный комплект не запускает соревнование. Профиль требует службу; скрытого перехода в ослабленный режим нет. Импорт/экспорт `.roundlane`, точный контест, фильтр сайтов и код выхода сохранены.

## Пределы проверки

Windows x64 сборка выполняется в ARM64 VM с эмуляцией. Это не заменяет проверку на настоящем x64 ПК. Сборка не подписана доверенным издателем. Manifest теперь имеет Ed25519 подпись Roundlane; проверка выполняется формой перед запуском и не является Authenticode или проверкой памяти. См. docs/independent-integrity-2026-10-11.md. Закрытый DLL проверки целостности SEB отсутствует в публичном checkout и не включён. MPL-2.0, исходные copyright notices и зависимые библиотеки сохранены.

Офлайн-проверка установленного каталога без запуска экзамена: `go run ./cmd/verify-runtime <INSTALL_DIRECTORY>`. Перед стартом та же проверка выполняется автоматически.

## Сохранение кода выхода

Код организатора сохраняется при закрытии окна, сохранении настроек и подтверждении старта. При следующем запуске под тем же пользователем Windows он восстанавливается из `%APPDATA%\Roundlane\organizer-code.dpapi`, зашифрованного DPAPI текущего пользователя. Общий файл `.roundlane` содержит только хеш; импорт участником не сохраняет открытый код.

## Запуск участника

Подписанный `competition.roundlane` рядом с установленным Roundlane задаёт соревнование для обычного запуска без панели. Ассоциация `.roundlane` передаёт открытый файл в тот же путь. Ed25519 проверяет ссылку и хеш; сам код в пакет не включён. `--organizer-tools` сохраняет доступ к подготовке.
