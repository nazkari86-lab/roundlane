# Проверка вкладок — 13 октября 2026

## Наблюдалось

- Xcode universal arm64+x86_64: BUILD SUCCEEDED. Подпись ad hoc с hardened runtime и отдельная подпись выпуска обновлены.
- Mac --tabs-check: восемь проверок разрешённых URL, удаления служебных параметров, отклонения посторонних адресов и сохранения исходного кода в query.
- Живая проверка --tabs-preview: общий производственный RoundlaneTabs и WKWebView с локальными тестовыми страницами; изолированный контроллер обычных окон, без kiosk и сети. Cmd+1/3, Ctrl+Tab / Ctrl+Shift+Tab, Cmd+T, Cmd+W и Cmd+Shift+T проверены. После перезапуска восстановились страницы и изменённый текст редактора. Панель просмотрена при ширине 1000 и около 560 pt, включая прокрутку при шести вкладках. Буквенные сочетания исправлены для русской раскладки.
- Windows .NET Framework Release/x64: Client, Runtime, Service, ResetUtility собраны в доступной Windows ARM64 VM; хеши девяти переданных файлов исходников сверены перед сборкой. В runtime изменены три DLL; остальной комплект совпадает с предыдущим выпуском.
- tests/tabs-workspace: 13 случаев пройдены на .NET 8 с тем же RoundlaneWorkspace.cs и тестовыми браузерными объектами. Сохранение и восстановление страниц/кода, закрытие/восстановление, большой Unicode-черновик, удаление параметров входа, посторонние адреса и повреждённый XML.

## Границы проверки

Безопасный Mac preview использует локальные страницы и отдельный контроллер окон; это проверка панели и сохранения, а не полного защищённого сеанса. Windows WPF/CEF сочетания в защищённом сеансе не репетировались. Физический Windows x64 недоступен. Долгая проверка защиты не повторялась по указанию пользователя. Предыдущая проверка Codeforces, компилятора и выхода описана в docs/security/live-rehearsal-2026-10-13.md; она не заменяет проверку этой панели в экзамене.

Страницы сохраняются отдельно для точной ссылки контеста, только HTTPS внутри выбранного контеста и cpp.sh. Исходный код сохраняется периодически; последние несколько секунд могут потеряться при аварии. Авторизацию Codeforces может потребоваться выполнить заново. Неверный/повреждённый файл рабочего пространства не блокирует запуск. Автозапуска приложения или экзамена не добавлено.
