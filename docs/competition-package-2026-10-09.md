# Roundlane: единый комплект установки

Результат: один скачиваемый ZIP с установщиком Windows и DMG Mac. На каждой платформе пользователь устанавливает Roundlane из одного файла, вручную задаёт группу/код и начинает соревнование. Mac 3.3 — universal arm64+x86_64 со встроенным публичный SEB classic runtime; Windows — Roundlane вместе с неизменённым официальным SEB и его зависимостями. Это единый установщик, а не новый fork Windows SEB.

## Изменения

- Windows 2.3 Full Setup содержит официальный SEB 3.10.2.920, VC++ x64 из manifest этого SEB и полный .NET Framework 4.8. Подписи зависимостей и их хеши проверяются перед упаковкой.
- Проверяются Windows x64, установленная версия SEB и .NET. Уже подходящий SEB не переустанавливается. При отсутствии компонента открывается его официальный установщик с обычными разрешениями/условиями. Отмена/ошибка прекращает установку Roundlane. Автоматическая перезагрузка и автозапуск экзамена запрещены.
- Финальный экран может открыть только форму организатора. Изменённые файлы/настройки других приложений не удаляются; удаление Roundlane не удаляет общий официальный SEB.
- Mac 3.3 собран для arm64 и x86_64; обе архитектуры также есть в helper. Intel runtime не проверен. Mac DMG содержит Roundlane.app, ссылку Applications и исходные изменения с лицензией. ZIP комплекта также содержит короткий список проверок перед олимпиадой, контрольные суммы и необходимые источники/лицензии.
- Сохранены минимальная форма, весь Codeforces, группа, cpp.sh, C++ шаблон, короткий видимый код и отдельное подтверждение блокировки.

## Результаты проверки, 10 октября 2026

Mac 3.3: основной executable, debug dylib и helper содержат arm64 и x86_64. Проверка ad hoc подписи `codesign --verify --deep --strict` и контрольной суммы DMG успешна. Self-test выполнен из сборки и ранее из смонтированного DMG. Безопасная подготовка профиля проверила код выхода, разрешённый выход, токен локального helper и очистку временного каталога; `exam_started=false`. Установленная версия совпадает со сборкой. Форма и подтверждение проверены, запуск отменён. На основном Mac блокировка не включалась.

Windows: финальный `Roundlane 2.3 Full Setup.exe` установлен в Windows 11 ARM64 VM с уже установленным SEB 3.10.2.920. Хеш гостевой копии совпал с выдаваемым файлом: `0c82d947de0afdf5c1ed54d9237f5ce81181779dfdab58d87201aa4f1763677b`. Регистрация показывает 2.3, установленные файлы совпадают со сборкой. Проверены форма, генерация кода 7484 и подтверждение с Ctrl+Q; подтверждение отменено. После закрытия нет процессов Roundlane/экзамена/установщика, слушателя 18765, временных каталогов сессии или записи Roundlane в проверенных Run-ключах. Официальная служба SEB работает.

Все ресурсы извлечены из финального установщика и сверены с исходными хешами. Подписи встроенных SEB, VC++ и .NET имеют статус Valid (ETH Zürich/Microsoft). Проверка отсутствующего executable SEB проведена на предварительном установщике с тем же сценарием NSIS: открылось окно официального компонента, отмена дала 1602 и остановила установку. Это симуляция отсутствующего файла при сохранённой регистрации SEB, а не чистая установка. Файл SEB восстановлен, подпись и хеш подтверждены. В финальном установщике используется раздельное сжатие LZMA: при уже установленном SEB большой блок зависимостей не распаковывается.

Экзамен Windows 2.3 в этой проверке не запускался. Предыдущие реальные проверки 2.2 (старт/выход) и 2.1 (сайты/компилятор/сочетания/перезагрузка) сохранены в отдельных отчётах и не выдаются за проверку новой версии. Чистая установка SEB/.NET/VC++, ветвь обязательной перезагрузки 3010, реальный x64 ПК, Intel runtime Mac и полноценный экзамен Mac пока не проверены. У Mac нет Developer ID/notarization; гарантии закрытых защитных модулей SEB не подтверждены.
