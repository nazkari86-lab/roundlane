# Codeforces Custom Invocation — Mac 3.9.2

## Причина

В Mac 3.9.1 страница `/group/<group>/contest/<contest>/customtest` открывалась, но кнопка «Запустить» оставляла вывод пустым. Подтверждено в установленном WKWebView под тестовым доменным аккаунтом. Исходный код страницы Codeforces использует POST `/group/<group>/data/customtest` для `submitSourceCode`, `getVerdict`, `saveSourceCode`, настроек редактора. Прежний фильтр не разрешал этот адрес: безопасный `--check-settings` и регрессионный тест подтвердили отказ.

## Изменение

В генераторы Mac и Windows добавлен только точный `/group/<выбранная группа>/data/customtest` на выбранном хосте, с необязательным query/fragment. Другие группы, похожие имена и подпути не разрешены. Защита процессов, подписанные настройки участника и код выхода не изменялись.

## Проверка

Сначала `TestOnlySelectedContest` падал на двух нужных URL. После изменения `go test ./core -count=1` прошёл; проверены запреты других групп, соседних адресов, контестов и сайтов. Сборка и проверка реального запуска записываются в `setup/codeforces-run-20261014`. Полная защищённая сессия на Mac и запуск на физическом Windows x64 в рамках этого исправления не проводятся.

В исправленном WKWebView Roundlane под тестовым user1 выбран GNU G++20 13.2. Код с `#include <bits/stdc++.h>` складывает два целых числа. После «Запустить» появился статус «Исполняется…», затем для ввода `2 3` показан вывод `5`, 15 мс, 8 КБ. На старой установленной версии тот же путь запуска оставлял вывод пустым. Обе архитектуры arm64 и x86_64 собраны Xcode; Intel-исполнение отдельно не проверялось. Windows генератор исправлен и проверен тестами core; Windows установщик в этом выпуске не пересобирался.
