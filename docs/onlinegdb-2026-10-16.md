# OnlineGDB в Roundlane 3.10.0

Вместо cpp.sh приложение открывает текущую размещённую версию OnlineGDB. По умолчанию выбран C++20; в IDE можно выбрать C++23 или C++26. Стартовый шаблон берётся из `starter.cpp`, включает стандартные заголовки, `using namespace std;`.

Доступны запуск, отладчик, несколько файлов, тестовый ввод, интерактивная консоль, аргументы программы, форматирование, импорт и скачивание исходников. Автоматическое открытие скачанных файлов и SEB конфигураций отключено. Для работы требуется интернет и доступность OnlineGDB; собственный сервер компиляции в установщик не входит.

Roundlane сохраняет локально до 32 файлов (262144 символа на файл, до 1 МиБ сериализованного проекта), активный файл, язык, аргументы, режим ввода и до 131072 символов stdin. При восстановлении редактор не перезаписывает уже начатую работу участника. Старые локальные черновики cpp.sh переносятся в OnlineGDB; обычная навигация на cpp.sh заблокирована.

В экзамене разрешены IDE и необходимые запросы OnlineGDB, Socket.IO, форматирование и точные пути внешних библиотек и обязательных загрузчиков рекламы OnlineGDB. Рекламные ссылки за пределами разрешённых адресов заблокированы. Страницы общих проектов, форумы и AI API не включены в разрешённые адреса; AI кнопка скрыта. Список ресурсов может потребовать обновления при изменениях на стороне сервиса.

## Проверки

Node: общий адаптер редакторов, шаблон, многофайловый проект, активный файл, язык, ввод, аргументы и отказ при повреждённых данных. Go: разрешённые ресурсы и запрещённые адреса, профиль и стартовая страница. .NET: восстановление файлов и многофайлового проекта при закрытии/перезапуске, перенос старого workspace.

Фактические проверки пакетов и сетевые результаты публикуются в `verification.json` выпуска. Сборка Windows выполняется в Windows ARM64 VM; это не заменяет репетицию экзамена на обычном Windows x64. Полная блокировка ОС в этой проверке на рабочем Mac не включается.

## Сетевая проверка на Mac

В безопасном окне с тем же URL whitelist проверены: C++20 и стартовый шаблон, компиляция программы с вводом `7 35` → `42`, успешное завершение (exit code 0), запуск и остановка GDB, создание второго файла `helper.h`. Полный сеанс пошаговой отладки не проверялся. Текстовый ввод подтверждён; отрисовка интерактивной консоли в WebKit требует отдельной проверки.

Загрузчик `html-load.com` перенаправляет запросы с Origin/Referer OnlineGDB на `stg.html-load.com`. Оба точных адреса включены в фильтр. При блокировании обязательных рекламных скриптов сервис показывает предупреждение и перезагружает страницу, поэтому они включены в разрешённые ресурсы. Это ограничение текущей бесплатной версии сервиса.
