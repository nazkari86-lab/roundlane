# Запуск участника из подписанного файла

Участник открывает `competition.roundlane` установленным Roundlane. Подпись Ed25519 проверяет точную ссылку и хеш общего кода выхода. Только подписанный формат `roundlane-participant` запускается без формы и подтверждения; старые неподписанные настройки сохраняют ручной старт.

В файл участников включены только ссылка, SHA-256 общего кода и подпись. Новый случайный код из 16 символов хранится только в `organizer-private/` и не включается в приложения, исходные архивы и файлы для участников. Стойкий случайный код затрудняет подбор по хешу; это не обещание защиты от администратора ОС или модификации приложения.

В текущие приложения включены проверенные настройки контеста 723396: обычный ручной запуск сразу начинает эту сессию. При успешной подготовке приложение сохраняет проверенный файл локально: следующий ручной запуск приложения снова открывает заданное соревнование без формы. Автозапуск при входе в ОС не добавляется. `--organizer-tools` открывает подготовку организатора; он не раскрывает код из подписанного файла. Изменённый или повреждённый файл приводит к ошибке без запуска экзамена и без подстановки кода 1234.

macOS обрабатывает открытие `.roundlane` через небольшой встроенный обработчик Launch Services; рабочий процесс запускает существующий встроенный runtime. Windows получает путь через зарегистрированную ассоциацию файлов. Конкурс и компилятор доступны в существующем интерфейсе вкладок. Выход сохраняется: Cmd+Q на Mac, Ctrl+Q на Windows, затем общий код организатора.

Проверка: тесты подписи и изменения данных, совместимость прежнего формата, безопасный запуск полного пути подготовки на Mac до загрузки SEB; обработчик macOS получает реальное событие открытия файла в диагностическом режиме. Основной Mac не блокируется. Проверка Windows выполняется на доступной ARM64 VM, что не заменяет физический x64 компьютер.
