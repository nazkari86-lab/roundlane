# Roundlane

Приложение для соревнований по спортивному программированию. Организатор вводит ссылку на конкретный контест Codeforces, выбирает код выхода и вручную начинает соревнование. После перезагрузки приложение само не запускается.

Исправление Mac 3.9.1: [загрузка страниц и сетевой процесс WebKit](docs/white-screen-2026-10-14.md).

Mac 3.9.2: исправлена кнопка «Запустить» внутри Codeforces — [причина и проверка C++20](docs/codeforces-run-2026-10-14.md).

Mac 3.9.3 и обновлённый Windows-установщик: [аудит ошибочных блокировок служебных запросов](docs/filter-audit-2026-10-14.md). Проверены отправка решения с Accepted, просмотр исходника/протокола и история в таблице в безопасном Mac-браузере.

Mac 3.9.4 и обновлённый Windows: [сохранение редакторов и запуск](docs/reliability-2026-10-14.md).

## Вкладки

Обновление: [Mac — DMG](../Roundlane-Mac-Tabs.dmg) · [Windows — EXE](../Roundlane-Windows-Tabs.exe). компактная панель страниц, «+», закрытие и восстановление закрытой вкладки. Страницы остаются загруженными при переключении. Список страниц, выбранная вкладка и черновики cpp.sh и редакторов Codeforces (отправка и тестовый запуск) сохраняются отдельно для каждого контеста; восстановление начинается после ручного старта соревнования. Cookie и пароли эта функция не сохраняет.

Ctrl/Cmd+T — новая вкладка; W — закрыть; Shift+T — вернуть закрытую; Tab / Shift+Tab — следующая / предыдущая; 1–8 — выбрать по номеру, 9 — последняя. На Mac поддержана русская раскладка. До 24 вкладок, панель прокручивается горизонтально. Исходный код сохраняется периодически: при внезапном завершении последние несколько секунд изменений могут потеряться.

[Проверка обновления вкладок](docs/tabs-verification-2026-10-13.md).

## Организатору

1. Откройте Roundlane и вставьте точную ссылку `https://…/group/…/contest/…`.
2. Оставьте **1234**, введите свой код или нажмите «Новый код». «Копировать» переносит код в буфер обмена. Код автоматически сохраняется при закрытии окна, сохранении настроек или подтверждении старта и восстанавливается при следующем запуске под тем же пользователем ОС. На Mac используется Связка ключей, на Windows — шифрование DPAPI текущего пользователя.
3. Нажмите «Начать соревнование». В подтверждении показаны группа, код и способ выхода. «Назад» или Escape отменяют старт.

Последняя подтверждённая группа запоминается. Ввод и комплект приложения проверяются автоматически. Enter в поле не начинает соревнование. До запуска компьютер остаётся доступен.


[Проверка сохранения кода выхода](docs/code-memory-2026-10-14.md).

### Режим участника

Текущий DMG и EXE содержат подписанные настройки контеста 723396. Участник открывает приложение — соревнование начинается сразу, без панели организатора и без поля кода. Открытие `competition.roundlane` также запускает указанное соревнование. Никакого автозапуска после входа в ОС или перезагрузки не добавляется.

Один случайный общий код из 16 символов сохранён только в `organizer-private/participant-launch-organizer.txt`. Не передавайте этот файл участникам. В подписанных настройках находятся только ссылка, SHA-256 и подпись Ed25519; приложения и исходные архивы не содержат сам код. Подмена ссылки или хеша отклоняется. Это не гарантия против администратора ОС или модификации приложения.

Для подготовки организатора используйте `--organizer-tools` и действующий код выхода пакета. Прежние неподписанные файлы `.roundlane` требуют ручного старта и сохраняются для совместимости. Создание нового подписанного файла выполняется отдельным инструментом `win-app/cmd/make-participant` с приватным ключом выпуска; этот ключ не включён в приложения и исходники.

[Схема и проверка запуска участников](docs/participant-launch-2026-10-14.md).

Первоначальная установка собственной службы Roundlane в Windows требует администратора ОС. Пароль администратора компьютера в файл не записывается. [Формат и проверка общих настроек](docs/shared-settings-2026-10-10.md).

Внутри доступны выбранный контест Codeforces, вход и его служебные ресурсы, а также cpp.sh с C++ шаблоном. Другие контесты, блоги и общий problemset закрыты. Нужна точная ссылка /group/…/contest/…. Остальные адреса блокирует URL-фильтр. Выход: **Cmd+Q** на Mac или **Ctrl+Q** на Windows, затем код организатора.

## Самостоятельная сборка

Windows 3.0 собирает из публичных исходников собственные Runtime, Client, Service и Recovery. Отдельный SEB не ищется и не запускается. ## Проверка сайтов до блокировки (Mac 3.6)

С 14 октября кнопка скрыта в обычном запуске и после загрузки настроек участника. Организатор может запустить приложение с `--organizer-tools`.

«Проверить сайты» открывает отдельный браузер с теми же разрешёнными адресами и штатным SEB User-Agent. Закрытие без кода; рабочий стол доступен. Cookie-хранилище временное, результаты не переносятся в защищённый экзамен. Codeforces / C++ / Назад / Обновить доступны в панели проверки.

Живая проверка 10 октября: Chrome автоматически прошёл Cloudflare и открыл форму входа. В режиме проверки Roundlane Mac Cloudflare зацикливался; прохождение не подтверждено. C++ шаблон в cpp.sh скомпилировался и завершился с exit 0. Вход в аккаунт и отправка решений не проверены. [Результаты и ограничения](docs/browser-check-2026-10-10.md).

Mac 3.6: исправлена блокировка служебных iframe/worker Cloudflare; в установленном приложении появилась CAPTCHA. В этой сессии Cloudflare пройден и форма входа Codeforces открылась. Вход в аккаунт, отправка решений и полный защищённый Mac экзамен не проверены. [Исправление и проверка](docs/cloudflare-fix-2026-10-10.md).

## Исправление запуска Mac 3.7

Исправлено тихое завершение после подтверждения: публичный runtime не содержит закрытый модуль, устанавливающий `_mainTLS`. Только target Roundlane использует явный `ROUNDLANE_PUBLIC_RUNTIME`; оригинальная проверка остаётся для остальных сборок. Это не воспроизводит защиту закрытого модуля официального SEB. Регрессионная проверка `--runtime-settings-check` теперь входит в сборку и требует успешный JSON-результат; одного exit 0 недостаточно. Установленная версия прошла инициализацию настроек и безопасный preflight. Полный защищённый Mac экзамен остаётся непроверенным. [Отчёт](docs/startup-fix-2026-10-10.md).

## Исправление аварии Mac 3.8

Восстановлена регистрация внутреннего документа браузера и создание документа до загрузки его окна. Регрессионная проверка создаёт настоящий встроенный SEB WebView без kiosk; включена в сборку. Полный защищённый запуск остаётся непроверенным. [Отчёт](docs/startup-crash-fix-2026-10-10.md).

## Один контест и доменные аккаунты

Mac 3.9 / Windows 2.6 формируют фильтр под введённый контест. Для выдаваемых user1–user30 используется официальный механизм Codeforces «Пользователи домена». Приватный список паролей организатора не входит в комплект участника. [Состояние и инструкция](docs/contest-domain-2026-10-10.md).

## Независимая проверка компонентов Windows

Сборка 11 октября добавляет подпись Ed25519 для списка компонентов, проверку всех хешей и отказ при неизвестных файлах runtime. Это проверка перед запуском из формы; защита памяти и доверенная подпись издателя не добавлены. [Результат и ограничения](docs/independent-integrity-2026-10-11.md).

## Собственная защита: выпуск 13 октября

В скачиваемый комплект включены периодические проверки памяти/целостности, terminal quarantine с выходом только по коду, Windows image-load policy и hardened runtime Mac. Mac дополнительно проверяет собственную Ed25519 подпись ресурсов и исполняемых компонентов, даже после повторной ad hoc подписи. Ключ выпуска в приложения/исходные архивы не включён. Windows генератор явно требует службу защиты.

[Mac подпись выпуска и тест изменения инструкций](docs/security/mac-release-binding-2026-10-11.md) · [требование Windows службы](docs/security/windows-service-required-2026-10-11.md) · [проверенные слои и ограничения](docs/security/platform-hardening-2026-10-11.md).

Windows Release6 прошла реальный WCF тест (8 случаев), репетицию с обязательной службой, блокировку при нарушении целостности и выход по коду после faulted channel с восстановлением рабочего стола. Установщик, DMG, исходники и общий архив проверены. Mac host kiosk не запускался. Перед олимпиадой остаются отдельный Mac, физический Windows x64 и фактическая отправка решения в Codeforces. Проверка сканера на отдельном arm64 процессе с тестовыми исключениями не доказывает обход hardened runtime, защиту системных WebKit/CEF процессов или гарантии против администратора/ядра ОС.
