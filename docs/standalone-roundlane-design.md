# Самостоятельный Roundlane

## Результат

Одна установленная программа Roundlane на каждой платформе. Экзаменационный браузер и блокировка собираются из публичных исходников SEB; наличие установленного SEB не проверяется и его установщик не запускается. Codeforces ограничен выбранным контестом; компилятор, общие настройки и ручной выход сохраняются.

## Реализация

Mac уже содержит SEB WebKit и classic kiosk в собственном bundle. Windows получает собственные Roundlane.Runtime, Roundlane.Client, Roundlane.Service и Roundlane.Recovery, собранные из checkout 167f82f8. Внутренние библиотечные namespace SafeExamBrowser и лицензионные уведомления сохраняются. Организационная форма Roundlane запускает только компонент внутри своего установленного каталога.

Windows IPC, mutex, журналы, cache, резервные настройки и служба используют отдельное имя Roundlane. Привилегированная служба устанавливается единожды администратором вместе с Roundlane; участники запускают приложение без прав администратора. Служба автоматически восстанавливает системные настройки после аварии; приложение не запускается при загрузке ОС. Предоставляется отдельное восстановление из исходников SEB.

## Проверка

Сборка .NET/WPF выполняется в тестовой Windows VM. Проверяются наличие собственных runtime/client/service, независимость от SEB, профиль и запуск. Mac проверяется без kiosk. Защищённый режим на рабочем Mac не запускается. Отдельно фиксируются непроверенные реальные Windows x64 и закрытые модули целостности SEB: их исходников в публичных checkout нет, эквивалентность официальной защите не заявляется.
