# Домен Codeforces и один контест

Официальный механизм: https://codeforces.com/blog/entry/51787?locale=ru — домены групп и синтетические пользователи домена. Указание единственного ID соревнования ограничивает аккаунт этим соревнованием.

10 октября создан домен roundlane723396 для существующей закрытой группы tqy1SBMbAa. Политики участников и зрителей: по приглашению. Саморегистрация домена выключена. Проверена отдельная форма входа по HTTPS.

Контест: https://roundlane723396.contest.codeforces.com/group/tqy1SBMbAa/contest/723396

В organizer-private подготовлены 30 строк импорта user1–user30, разные случайные шестизначные пароли и карточки для печати. Это приватные файлы организатора; они не включаются в приложения, исходники и общий архив. Пользователь сообщил, что вручную сохранил импорт и вошёл первым участником. В Chrome непосредственно подтверждён вход «Участник 1»; остальные 29 входов отдельно не проверены.

Mac 3.9 / Windows 2.6: ссылка обязана содержать конкретный /group/ID/contest/ID. Разрешены выбранный контест, страница входа, список соревнований его группы, служебные ресурсы этого хоста, assets.codeforces.com, Cloudflare, cpp.sh и локальная стартовая страница. Обычный Codeforces закрыт при выборе домена; другие домены, контесты, профили, блоги и problemset не разрешены. В группе только один контест; в аккаунтах указан только 723396. Список соревнований группы нужен для перенаправления после входа.

Профиль формируется из фактически введённой ссылки при каждом старте и при проверке сайтов. Старые файлы только со ссылкой на группу больше не подходят: нужна точная ссылка на контест. URL-фильтр не заменяет серверные права на просмотр исходников и служебные запросы /data; они обеспечиваются доменными аккаунтами и настройками контеста.

Проверки: Go core tests, создание настоящего SEB WebView без kiosk, проверка динамических правил Mac на нужных/посторонних URL. Полный защищённый режим и отправка решения остаются отдельными проверками. Windows installer собран на Mac; обновлённая версия не проверена на настоящем Windows.

10 октября, около 21:09 UTC+5, в существующей сессии Chrome непосредственно проверены страницы участника: список содержит только контест 723396; доступны задачи A–C, форма отправки с выбором GNU G++17/20/23 и страница «Мои посылки» (пока пустая). Тестовый контест закончен и доступен для дорешивания, время настоящей олимпиады не назначено. Решение не отправлялось; работа judge и вход участника внутри Roundlane этим наблюдением не подтверждаются.

WebKit сначала отклонил объединённые регулярные выражения с |. Правила разделены на отдельные выражения без дисъюнкции; проверка выполняется реальным WKContentRuleListStore.

Фактически наблюдалось в безопасном браузере Mac 3.9: форма входа доменного сайта загружена; ссылка Privacy Policy вне разрешённых страниц заблокирована. WebKit compilation passed. Самопроверка Mac включает 17 разрешённых/запрещённых URL. Снимки сохранены в setup/contest-only-check.
