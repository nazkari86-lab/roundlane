# Roundlane 3.9.5: восстановление черновиков

Исправлено раздельное восстановление исходника и тестового ввода. Если участник уже изменил только stdin, сохраняется этот новый ввод и восстанавливается сохранённый код; если изменён только код, восстанавливается ещё не изменённый ввод. Ошибка воспроизведена двумя падавшими проверками до исправления.

Адаптер использует существующий экземпляр Ace: вызов ace.edit на ещё не подготовленном контейнере может создать пустой редактор. Ожидание iframe Codeforces editArea не заменяет сохранённый буфер старым значением скрытого textarea. Некорректный исходник не восстанавливает ввод частично.

Добавлены автоматические проверки GitHub: JavaScript, Go core, компиляция Windows launcher, .NET fixtures вкладок и выхода. Actions закреплены по точным commit SHA, права workflow ограничены чтением содержимого. Это проверки компонентов, они не подтверждают блокировку ОС и совместимость всех текущих сайтов.

Интерфейс участника, выбранный контест и код выхода сохраняются. Обновлённый адаптер включён в ресурсы Mac и в Browser DLL Windows.
