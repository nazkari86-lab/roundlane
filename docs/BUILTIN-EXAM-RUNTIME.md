# Roundlane со встроенным экзаменационным режимом

## Цель

Roundlane должен быть самим экзаменационным приложением для Mac и Windows: после ручного запуска он показывает браузер, навигацию и выход внутри собственного окна. Пользователю не требуется отдельная установка Safe Exam Browser. Организатор задаёт точную ссылку на контест Codeforces; внутри доступны выбранный контест и cpp.sh. Остальные сайты и приложения блокируются на уровне экзаменационного режима. После выхода по известному организатору коду компьютер возвращается в обычное состояние. После перезагрузки Roundlane не запускается сам.

## Самостоятельная сборка, 10 октября

Mac 3.9 содержит встроенный публичный runtime. Для Windows 3.0 собраны собственные Runtime, Client, Service и Recovery из публичного checkout; перенос и проверка установщика описаны в docs/standalone-roundlane-design.md. Отдельный SEB больше не входит в новый установщик. Закрытые модули целостности отсутствуют на обеих платформах.

## История реализации

Roundlane 2.1 — отдельный настройщик. Он создаёт `.seb`, запускает установленный SEB и закрывается. В нём нет собственного защищённого браузера или системной блокировки. Пакеты 2.1 нельзя представлять как реализацию этой цели.

9 октября 2026 подготовлены исходники: `upstream/seb-mac` на теге `3.7.1` (`a1e3f786aac4aa2e827998dcf8ca139f2c5205a9`, весь публичный checkout, около 311 MiB с Git) и `upstream/seb-win-refactoring` на ветке `3.10.2` (`167f82f8c3ec6773ec9be6c5af7fb492b5b2ed50`). Mac checkout используется для локальной версии Roundlane 3.1; native Windows build пока не собран.

## Локальная сборка Roundlane 3.1 Development

9 октября собран arm64 Mac пакет `native-mac/dist/Roundlane 3.1 Development.zip` и установлен в `/Applications/Roundlane.app`. В нём публичный SEB браузер и классический kiosk mode скомпилированы в Roundlane. Отдельный установленный SEB не запускается. Bundle ID — `local.roundlane.exam`; собственная иконка, форма группы/кода, временный профиль и локальный hub сохранены.

Профиль принудительно задаёт `lockdownModePolicy=1` (`lockdownModePolicyEnforceClassic`). В исходниках SEB `updateAACAvailablility` при этом сразу отключает AAC. Требование сертификата/assessment entitlement, ранее добавленное в Roundlane 3.0, снято именно для этого штатного режима. Разрешение Apple требуется для AAC, а не для запуска любого личного приложения или classic kiosk mode. Подпись пакета — ad hoc.

Сборка, self-test, подпись и проверка запуска без блокировки прошли. В установленном приложении кнопка «Начать» доступна, код `1234` виден, Enter в поле не начинает экзамен. Второе подтверждение повторяет код; Back/Escape и закрытие формы проверены. Проверка `--preflight-check` создала временный профиль с разрешённым выходом, проверила токен локального hub и удалила файлы, не загружая SEB. Экзаменационная блокировка, сайты внутри неё и восстановление рабочего стола после настоящей сессии ещё не проверены. Classic mode не приравнивается к AAC или закрытым защитным модулям официальной сборки.

Прежняя проверка Windows ISO отклонила его по английской строке таблицы. Повторная проверка 9 октября показала точное совпадение с другой опубликованной строкой Microsoft; EN-US подтверждается volume label и lang.ini. Расхождение строки хэша и локали записано отдельно. VM Roundlane Windows Test создана; Windows установлен и рабочий стол наблюдался. Гостевые инструменты, Roundlane 2.1 и официальный SEB 3.10.2 установлены; интерфейс Roundlane и диагностика проверены. В SEB на Windows ARM64 VM проверены Codeforces, выполнение C++ шаблона с exit status 0, три запрещённых сайта, системные сочетания, выход по 1234 и восстановление рабочего стола; после выхода и перезагрузки автозапуска нет. Для запуска понадобились два тестовых параметра VM; производственный профиль восстановлен. [Отчёт проверки](windows-verification-2026-10-09.md). Native Windows build пока не готов. Подробности: `native-mac/README.md`, отчёт `native-macos-build-2026-10-09.json` и сборка `scripts/build-native-mac.sh`.

## Обновление интерфейса 3.2 / 2.2

Mac 3.2 и Windows 2.2 получили компактную форму организатора: автоматическая валидация, короткий генератор кода, копирование, нормализация группы и отдельное подтверждение соревнования. В собственном Mac runtime убраны стартовый About SEB и команды About/Help/Settings; лицензионные уведомления сохранены. Windows 2.2 по-прежнему использует отдельно установленный официальный SEB. [Сценарий и проверки](admin-experience-2026-10-09.md).

## Выбранная архитектура

1. Взять поддерживаемые исходники SEB для каждой платформы и создавать собственные сборки экзаменационного приложения под именем Roundlane. Использовать штатные механизмы блокировки и браузера SEB, а не имитировать их поверх WebKit или Chromium.
2. Сохранить минимальную организационную форму: ссылка на группу, видимый код выхода, проверка готовности и отдельное ручное действие «Начать». Внутри экзаменационного окна — стандартная навигация SEB, ссылка на группу и cpp.sh.
3. Перед входом проверять конфигурацию, доступность выхода и сайтов. Оставить выход по короткому коду; не сохранять код в постоянных настройках. Обеспечить восстановление обычного рабочего стола при ошибке и после завершения.
4. Выпускать самостоятельные подписанные приложения для Mac и Windows. Установщик не создаёт автозапуск. Публикация требует проверки лицензий, собственных подписей и испытания на обеих платформах.

## Условия для реализации

- **Mac.** Xcode 26.2 (17C52) установлен в `/Applications/Xcode.app`, подпись всего bundle проверена. Первоначально сборка требовала принятия соглашения Xcode и Apple SDKs. Позже первичная настройка завершена пользователем: `xcodebuild -checkFirstLaunchStatus` возвращает 0, схема Mac разрешается и компиляция запускается. Исходники SEB Mac требуют Xcode workspace и собственной подписи. README SEB описывает assessment entitlement для AAC и отсутствие некоторых бинарных защитных модулей; классический режим выбирается отдельно через policy 1 и не использует AAC. Установленный официальный SEB 3.7.1 подписан с `com.apple.developer.automatic-assessment-configuration`.
- **Windows.** Исходники SEB Windows — проект .NET Framework 4.8/WPF (`SafeExamBrowser.sln`), требующий Windows и соответствующих инструментов для сборки и проверки. Mac собирает Go-настройщик, а Windows ARM64 под UTM позволил проверить перечисленные сценарии SEB. Сборка native Windows и испытание производственного профиля на реальном x64 ПК ещё не выполнены.
- **Права на распространение.** До сборки собственного SEB нужно проверить условия лицензирования каждой платформы и возможность использования недоступных публично компонентов. Windows-репозиторий содержит MPL-2.0; отсутствие лицензии в метаданных Mac-репозитория само по себе не даёт права предполагать аналогичные условия.
- **Ресурсы.** 9 октября удалены неактивные кэши обновлений, старые незавершённые загрузки и кэши Go/npm. Полностью одинаковые файлы моделей и данных переведены на APFS copy-on-write с проверкой SHA-256 и сохранением содержимого. После первоначальной очистки, до удаления согласованных моделей, свободно 33.29 GB; цель 100 GB не достигнута. Уникальные проекты, готовые модели, PostgreSQL, Docker и файлы синхронизации сохранены. Отчёты: `storage-cleanup-2026-10-09.json` и `apfs-dedup-2026-10-09.json`.
- **Дополнительная очистка с согласия пользователя.** Через `ollama rm` удалены `gpt-oss:20b`, `qwen2.5vl:3b`, `hf.co/HauhauCS/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive:Q4_K_M`, `qwen3.5:2b`, `qwen3.5:9b-q4_K_M`. Измерено освобождение ещё 32.76 GB. `ollama list` подтверждает сохранение Ornith и обеих embedding-моделей. Отчёт: `ollama-cleanup-2026-10-09.json`. Значение 100 GB свободного места всё ещё не достигнуто.
- **Текущее рабочее место.** UTM 4.7.5 установлен в `/Applications/UTM.app`, подпись проверена. Через авторизованный браузер Apple скачан и установлен совместимый Xcode 26.2 Apple Silicon; первичная настройка завершена. Отчёт: `xcode-installation-2026-10-09.json`. Текущий Xcode 27 из App Store требует более новой macOS. Загрузка Windows 11 ARM 26H2 завершилась. Прежняя проверка по английской строке таблицы не прошла, но повторная проверка нашла точное совпадение с опубликованной строкой Arabic 64-bit; сам ISO имеет EN-US metadata. Образ переведён в `.iso`, подключён к отдельной тестовой VM. Ожидаемый SHA-256 именно английской строки таблицы: `DBF606CEB4CE1390F9F21AD1D96331848BC6B701CBAB0012785881A1A1C0EC63`. Windows впоследствии установлен; Roundlane 2.1 и экзаменационная сессия официального SEB проверены в VM в объёме отчёта Windows. Локальная Windows ARM VM на Apple Silicon не заменит проверку x64-сборки на Windows ПК.
- **Подтверждённые зависимости Mac.** Проверены ссылки build phases macOS target: отсутствует `Frameworks/libSEBSupport.a`; исходники, ресурсы и headers этого target присутствуют. Снятие sparse checkout восстановило публичные зависимости, включая проект mbedTLS. Первый запуск компиляции подтвердил ошибку линковки `library SEBSupport not found`. После удаления только macOS link reference публичный код успешно собрался без неразрешённых символов. Закрытая библиотека не подменяется заглушкой; эквивалентность официальной защите не подтверждена.
- **Аккаунт Apple.** `security find-identity -v -p codesigning` возвращает 0 действующих сертификатов. Страница аккаунта предлагает вступить в Developer Program; форма запроса Automatic Assessment Configuration перенаправляет на `unauthorized` с сообщением, что аккаунт не имеет доступа. Членство, одобрение Apple и provisioning profile пока не получены.
- **Запуск UTM.** Старая запись KaliLinux в Documents блокировала запуск при чтении файла. После резервного копирования настроек отключено автоматическое восстановление этой записи; файлы KaliLinux не изменены. UTM снова открывает главное окно. Резервная копия: `~/Library/Application Support/Roundlane/SetupBackups/UTM-before-setup-2026-10-09.plist`. Не подменять весь файл настроек этой копией после создания новых VM: старая запись должна быть восстановлена отдельно, когда её файлы снова доступны.
- **Контроль загрузок.** `scripts/verify-windows-image.py` после завершения загрузки сверяет SHA-256 с опубликованным Microsoft и только после совпадения меняет суффикс `.iso.part` на `.iso`. Проверка на заведомо неверном файле подтвердила отказ без удаления файла и без создания готового `.iso`. До записи `sha256_verified` в `setup/windows-image-verification.json` образ не считается проверенным.

## Критерии готовности

1. На чистых Mac и Windows установка одного пакета Roundlane достаточна; отдельный SEB не установлен.
2. В экзаменационном режиме процесс, окно, иконка, меню и экранные диалоги принадлежат Roundlane. Доступны Codeforces, ссылка на группу и cpp.sh; произвольный URL блокируется.
3. Переключение к посторонним приложениям и системным средствам закрыто штатными механизмами каждой платформы. Проверены доступность короткого кода выхода и восстановление рабочего стола после штатного выхода, аварии и перезагрузки.
4. Проверены вход в Codeforces, задачи, отправка, несколько окон, работа компилятора и сетевые ограничения на реальных Mac и Windows. Проверка конфигурационного файла или HTTP 200 не считается доказательством защищённой сессии.

## Ограничения сборки Windows, найденные в исходниках

В закреплённом checkout используются .NET Framework 4.8, WPF, CefSharp и WiX v3.11+. `Setup/Setup.wixproj` и `SetupBundle/SetupBundle.wixproj` содержат команды подписи сертификатом исходного издателя; применять их для Roundlane нельзя. До выпуска установщика нужны собственная конфигурация подписи и отдельная проверка изменений. `Setup` также восстанавливает generated Components через `git checkout` в PostBuildEvent: при подготовке fork необходимо сохранить изменения установщика. Visual Studio Build Tools bootstrapper уже скачан с официального Microsoft URL, но установка и сборка в Windows ещё не выполнялись.
