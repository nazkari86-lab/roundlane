# Исследование для Roundlane 2.1

Проверено 9 октября 2026. Сохранены требования: весь Codeforces, группа организатора, cpp.sh, отдельная установка на каждом компьютере, минимальный интерфейс и видимый выход.

## Что добавлено

- Проверка локальной страницы, C++ шаблона, профиля и установки SEB до блокировки компьютера. Ручная проверка HTTP-доступности Codeforces и cpp.sh показывает код ответа; HTTP 403 не выдаётся за готовность сайта.
- В профиле включены поиск по странице, масштаб страницы и текста, часы, навигация и предупреждение перед перезагрузкой основного и дополнительного окна. Ключи сверены с официальной документацией и текущим Windows-кодом SEB.
- Ссылки загружаются независимо, с ограничением времени и повтором при ошибке. Рабочая ссылка остаётся доступной, если другой ресурс не загрузился.
- Запуск выполняется в фоне, повторное нажатие и изменение кода во время запуска отключены. В Windows используется найденный исполняемый файл SEB, а не произвольная ассоциация `.seb`.
- Новое имя Roundlane и единая векторная иконка R. Ссылка на группу переносится из предыдущих версий.

## Что не следует обещать

- SEB на Mac и Windows использует отдельные окна; это не вкладки Chrome. Включена штатная панель переключения SEB.
- cpp.sh компилирует через Emscripten и запускает WebAssembly в браузере. Это не идентичная среда GNU C++ Codeforces. Мы сохранили cpp.sh по выбору пользователя и явные стандартные заголовки C++17.
- Обычная HTTP-проверка не проверяет вход в аккаунт, антибот-проверку, компиляцию и работу внутри SEB. Самооценка пакета также не доказывает невозможность выхода из киоска.
- Для будущего автономного компилятора нужна отдельная песочница и проверка ограничений сети/процессов. Запуск непроверенного C++ прямо на компьютере участника не добавлен.
- Полноценный контроль использования SEB требует поддержки экзаменационной платформы; обычная ссылка на группу Codeforces этого не обеспечивает.

## Источники

- [SEB: macOS user manual](https://www.safeexambrowser.org/macosx/mac_usermanual_en.html) — окна, панель, масштабирование, необходимость тестирования целевой платформы.
- [SEB: Windows configuration keys](https://github.com/SafeExamBrowser/seb-win-refactoring/blob/master/SafeExamBrowser.Configuration/ConfigurationData/Keys.cs) — реальные имена настроек поиска, масштаба и предупреждений перезагрузки.
- [SEB: configuration specification](https://www.safeexambrowser.org/developer/documents/SEB-Specification-ConfigKeys.pdf) — совместимые параметры профиля.
- [C++ Shell: about](https://cpp.sh/about.html) — компиляция на сервере и выполнение WebAssembly в браузере.
- [ICPC: programming environment](https://image.icpc.global/icpc2026/environment.html) — важность определённого набора компиляторов и инструментов соревнования; это ориентир, не заявленная совместимость Roundlane с ICPC.
