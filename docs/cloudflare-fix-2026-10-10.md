# Cloudflare: Mac 3.6

Причина локального зависания: фильтр запрещал `about:srcdoc` iframe и `blob:` workers, создаваемые Cloudflare. Диагностика фиксировала BLOCKED NAV about:srcdoc и создание blob workers под codeforces.com/challenges.cloudflare.com.

В режиме проверки и защищённом runtime исправлена обработка служебного iframe: только неосновной фрейм, только HTTPS-источник Codeforces/Cloudflare; в runtime дополнительно требуется разрешённый URL источника. В фильтр ресурсов добавлены только blob этих двух уже разрешённых origins. Явные запреты применяются последними. Сетевые домены, kiosk, код выхода и штатная строка SEB не менялись.

Сравнение: стандартный WebKit с фильтром зависал; без фильтра показал CAPTCHA. С исходной строкой SEB и исправлениями srcdoc/blob CAPTCHA тоже появилась. В установленном Roundlane 3.6 без диагностических JS-вставок появился checkbox «Подтвердите, что вы человек».

Сборка arm64/x86_64, подпись, self-test и проверки фильтра прошли. Проверены разрешённые blob, запрет Google/чужих blob/похожих доменов, приоритет явного deny, отсутствие добавленных разрешений для других профилей.

При следующем наблюдении в 19:10 местного времени в установленном Roundlane 3.6 открылась обычная форма входа Codeforces, без Cloudflare. Агент не нажимал галочку: страница уже была открыта к моменту подтверждения пользователя. Каким действием завершилась проверка между наблюдениями, не установлено. Доступ после Cloudflare до формы входа подтверждён в этой сессии. Полный Mac экзамен и вход/отправка решений не проверены. Защита компьютера не запускалась.
