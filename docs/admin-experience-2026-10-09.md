# Интерфейс организатора

Цель: настроить и вручную начать соревнование на отдельном компьютере, сохранив понятный выход.

## Принятый сценарий

- Нативная форма: ссылка на группу, видимый код выхода, автоматическое состояние готовности и «Начать соревнование».
- Код по умолчанию 1234; новый короткий код из четырёх цифр создаётся по отдельной кнопке. Код можно скопировать. Код не сохраняется между запусками.
- Последняя подтверждённая группа запоминается. Ввод без `https://` принимается и нормализуется. Чужой домен, учётные данные в URL и неверный код отклоняются до запуска.
- Неверный ввод показывает конкретную ошибку; пустая форма показывает нейтральную подсказку. Повторный старт во время подготовки исключён.
- Перед блокировкой отдельное подтверждение показывает группу, код и сочетание выхода. Escape и «Назад» отменяют старт; Enter в поле не запускает экзамен.
- Убираются лишний заголовок внутри формы, длинные инструкции, ручная диагностика как обязательный шаг и рекламные ссылки/заставка SEB из собственного Mac runtime. Лицензионные уведомления остаются в составе приложения.
- В соревновании остаются нужные ссылки на группу и компилятор. Функции блокировки и разрешённые сайты сохраняются.

## Проверка

Сборки native Mac, прежнего Mac launcher и Windows launcher; self-test/profile tests; визуальный осмотр нативных окон и состояний на Mac и Windows VM; клавиатура, валидация, генерация/копирование кода и отмена подтверждения. На Mac проверка останавливается перед блокировкой и дополнительно проходит безопасный preflight. Нативный Windows runtime не входит в эту правку интерфейса и остаётся отдельным незавершённым артефактом проекта.

## Наблюдаемый результат

| Версия | Проверено |
| --- | --- |
| Mac 3.2, встроенный публичный SEB | Сборка arm64, подпись, self-test; установленная версия совпадает с пакетом. Пустая группа, неверный домен и код, генерация/копирование/вставка, Enter в поле, нормализация ссылки, подтверждение и Escape. Узкая и широкая форма. Повторный запуск помнит подтверждённую группу, сбрасывает код на 1234. Тестовая группа после проверки удалена из настроек. |
| Mac launcher 2.2, universal | Сборка arm64+x86_64, подпись, self-test, DMG и ZIP. Неверный домен и код, генерация/копирование/вставка, Enter в поле, нормализация ссылки, подтверждение и Escape, узкая/широкая форма. Полная сессия не запускалась. |
| Windows launcher 2.2, x64 | Go tests и vet, Portable ZIP; установка в Windows 11 ARM64 VM. Все установленные файлы совпали с dist по SHA-256, версия в реестре 2.2. Проверены состояния ввода, клавиатура Tab/Space, новый код и буфер обмена, подтверждение и отмена, узкая/широкая форма и иконка. Итоговая сборка начала сессию SEB с новым кодом 4084; Ctrl+Q и этот код вернули рабочий стол. |

Mac preflight с новым кодом подтвердил quit hash, доступный выход, создание профиля, токен локального сервера и удаление временного каталога. Экзамен на этом Mac не запускался. Отдельно проверено отображение ошибки подготовки в форме; это проверка сообщения, а не реальной ошибки запуска helper.

Для сессии Windows использована только гостевая копия профиля с двумя прежними VM исключениями: `allowVirtualMachine=true`, `allowedDisplaysIgnoreFailure=true`. После выхода восстановлен производственный профиль с проверкой SHA-256. Проверены отсутствие экзаменационных процессов, слушателя 18765 и временных каталогов. Эти исключения не входят в скачиваемые пакеты.

Повторный ручной запуск Windows после выхода снова показал форму с запомненной группой и кодом 1234. Минимальная ширина итогового установленного приложения проверена отдельно; затем форма закрыта.

Удаление меню About/Help/Settings и стартовой заставки встроенного Mac runtime подтверждено исходниками и сборкой; во время настоящего Mac экзамена не наблюдалось. Внешний официальный SEB в Windows сохраняет свои системные диалоги и брендирование. Проверка на ARM64 VM не подтверждает защиту реального x64 ПК. Вход в Codeforces и отправка решений не проверены; Test123 — фиктивная группа. Ранее проверенные сайты/компилятор и перезагрузка относятся к версии 2.1 и перечислены в отдельном отчёте.
