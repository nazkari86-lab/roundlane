# Сохранение кода выхода — 14 октября 2026

Код организатора автоматически сохраняется при закрытии окна, сохранении общих настроек и подтверждении начала соревнования. При следующем запуске под тем же пользователем системы он восстанавливается.

- macOS: Generic Password в Связке ключей пользователя. В UserDefaults код не записывается.
- Windows: DPAPI текущего пользователя; `%APPDATA%\Roundlane\organizer-code.dpapi`. Запись через временный файл с заменой.
- Импорт `.roundlane` не сохраняет открытый код. Общий файл по-прежнему содержит только SHA-256.
- Если сохранённый код недоступен или повреждён, поле остаётся пустым с сообщением: приложение не подставляет 1234 вместо недоступного кода.
- Обычные диагностические запуски Mac не затрагивают реальный код. Проверка перезапуска использовала отдельную временную запись, удалённую после проверки.

## Проверено

Mac: сборка arm64 и x86_64; шесть проверок Keychain; видимое восстановление тестового кода после закрытия и повторного открытия формы без блокировки рабочего стола; проверки политики контеста, вкладок и целостности.

Windows: тесты core, сборка x64; нативные тесты DPAPI в доступной ARM64 VM под SYSTEM: создание, отсутствие открытого кода в файле, чтение, замена, отказ от неверного кода и повреждённых данных. Подписанный runtime не изменялся; проверен отдельно. Это не проверка перезапуска формы под обычным интерактивным пользователем и не проверка физического Windows x64.

Свидетельства и результаты проверки пакетов: `setup/code-memory-20261014/`. Защищённый экзамен на основном Mac в этой проверке не запускался. Mac подписан ad hoc, без нотариализации Apple.
