# Аудит ошибочных блокировок — 14 октября 2026

## Проверенный объём

Под тестовым доменным участником проверены восемь страниц выбранного контеста: задачи, отдельная задача, отправка, свои посылки, статус, положение, все условия и запуск. Проверены служебные URL в HTML/JavaScript Codeforces, PushStream и cpp.sh. Локальные снимки и результаты находятся в `setup/filter-audit-20261014`; в распространяемые исходники учётные данные и авторизованные HTML-снимки не включены.

## Исправления

Фильтр ранее разрешал страницы `/group/<group>/contest/<contest>/…`, но блокировал AJAX группы. В Mac 3.9.3 и генераторе Windows добавлены точные адреса на выбранном хосте:

| Адрес после `/group/<выбранная группа>/data/` | Назначение |
| --- | --- |
| `customtest` | Запуск, результат, сохранение кода и настройки редактора; исправлен ранее |
| `submitSource` | Просмотр исходника посылки |
| `judgeProtocol` | Протокол проверки и ошибка компиляции |
| `submissionVerdict` | Обновление вердикта |
| `standings` | История отправок в таблице |
| `contests` | Названия задач/участников в новых строках статуса |
| `newProblemQuestion` | Вопрос по задаче |
| `changeProblemQuestionOrAnnouncementDataPage` | Страницы вопросов и объявлений |

PushStream выбранного домена использует `wss://<host>/ws/<channels>` и HTTPS `/ws/`, `/ev/`, `/lp/`. Их адреса также разрешены. Внешние домены, другие группы, похожие имена и лишние подпути AJAX остаются запрещены. Запросы изменения типа участника, ответа/модерации вопросов и публикации в PushStream `/pub/` не разрешены. Codeforces проверяет права аккаунта и параметры общих AJAX-маршрутов на сервере; фильтр URL не проверяет содержимое POST.

Блокировка `manifest.json` не мешает участию: это установка сайта как PWA. Google Analytics и ссылка на прежний внешний компилятор остаются закрыты. Найденная сканером строка `edit_area/\\` является частью шаблона JavaScript, а не реальным ресурсом.

## Наблюдения в настоящем WKWebView

- На старой версии нажатия на номер своей посылки и ошибку компиляции не открывали результат. В исправленной версии открылись исходник и полный протокол.
- Отправлено решение задачи A через форму выбранного тестового контеста. Посылка **394456461**, GNU G++20, получила **«Полное решение»**, 62 мс. Страница своих посылок показала результат без ручной перезагрузки; транспорт обновления отдельно не измерялся.
- Двойной щелчок по своей ячейке A в standings открыл историю с новой принятой посылкой.
- Пустая форма вопроса получила серверную ошибку «Поле должно быть не пусто». Сообщение организаторам не создано; доставка непустого вопроса и пагинация с большим числом сообщений отдельно не проверялись.
- Codeforces Custom Invocation: сохранённый C++20 код для ввода `7 35` вернул **42**, 15 мс, 0 КБ.
- cpp.sh: C++20 программа вывела **42**, завершилась с **exit status 0**. Расширять его список URL не потребовалось.
- Вход и выход Codeforces прошли; выход вернул разрешённую форму авторизации.

## Автоматические проверки и границы

Регрессионный тест сначала подтвердил блокировку нужных AJAX и PushStream URL. После изменения `go test ./core -count=1` прошёл. Реальный генератор Mac разрешает все 18 выделенных служебных URL; встроенный self-test проверяет 39 случаев. Проверены запреты других групп, посторонних сайтов и административных маршрутов. CodeRabbit рассмотрел отдельные выдержки двух генераторов: замечаний нет. Это дополнительное ревью, а не гарантия отсутствия всех дефектов.

Обе архитектуры Mac собраны. Безопасный браузер не включает kiosk и использует временные cookie. Windows-установщик собирается с тем же исправлением генератора; нативный runtime Windows не меняется. Полная защищённая сессия Mac, доставка объявлений во время реального контеста, исполнение на Intel Mac и физическом Windows x64 в этом аудите не проверялись. Проверенные сценарии не покрывают все будущие изменения Codeforces и все сетевые сбои.
