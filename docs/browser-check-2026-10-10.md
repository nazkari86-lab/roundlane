# Проверка сайтов до соревнования

Задача: сначала проверить Codeforces/Cloudflare, затем улучшить надёжность подготовки, сохранив минимальную форму и ручной запуск экзамена.

Обычный HTTP-запрос не проверяет JavaScript и Cloudflare. Переход на другую браузерную платформу потребует замены защитного runtime. Выбран небольшой отдельный режим проверки в Mac-приложении: системный WKWebView, штатный SEB User-Agent, те же разрешённые URL и фильтр подресурсов; до входа в код SEB и без блокировки рабочего стола. Кнопка «Проверить сайты» открывает этот режим отдельным процессом. Его окно прямо обозначено как проверка без блокировки; закрывается без кода. Cookie-хранилище временное, аккаунт/Cloudflare cookie не переносится в экзамен. Результат проверки не равнозначен полноценной защищённой сессии.

Производственный Mac-профиль явно выбирает современный WKWebView. Фильтры остаются узкими: Codeforces, assets Codeforces, challenges.cloudflare.com, cpp.sh, локальная стартовая страница. Произвольные домены и внешняя авторизация Google/VK не разрешаются. Для Codeforces проверяется обычная форма хэндл/пароль.

Генератор обеих платформ создаёт случайный пароль из 12 легко различимых латинских букв и цифр. Ручной пароль пользователя сохраняется допустимым; максимальная длина расширена до 32. При экспорте короткого пароля показывается предупреждение о подборе по SHA-256 и возможность отменить сохранение. Никакой реальный пароль не встраивается в исходники или общедоступный установщик.

Наблюдаемый результат: форма входа Codeforces и автоматическая проверка Cloudflare наблюдаются в браузерах; ручная CAPTCHA требует отдельного подтверждения, пароль аккаунта вводится пользователем. Windows проверяется в изолированной VM через официальный SEB, с двумя тестовыми разрешениями VM/дисплеев, затем исходный профиль восстанавливается. Mac проверяется без запуска киоска. Проверяются фильтры разрешённых и запрещённых URL, сборки, импорт прежних настроек, предупреждение слабого кода, отмена и готовый архив.

Cloudflare официально отмечает ограниченную поддержку встроенных браузеров и отличия VM от реального устройства: https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/. Прохождение на всех компьютерах гарантировать нельзя; нужна репетиция на сети и компьютерах олимпиады.

Стартовая страница: при проверке Windows 2.4 оба fetch-запроса прерывались по таймауту 30 секунд. В 3.5/2.5 оба локальных сервера формируют HTML с готовыми экранированными ссылками, без JavaScript и дополнительных запросов к конфигурации/шаблону. Шаблон C++ проверяется при старте helper, передаётся в query-параметре source. Фиксированный URL-фильтр сохраняется.

## Фактический результат 10 октября

- Chrome: Cloudflare автоматически пройден, форма входа открылась.
- Mac 3.5 WKWebView: Cloudflare зацикливается; доступ к Codeforces не подтверждён. Компилятор выполнил шаблон с exit 0; Google заблокирован. Проверка безопасная, не защищённый экзамен.
- Windows 2.5 + официальный SEB 3.10.2 в Windows 11 ARM VM: обе ссылки появились сразу; Codeforces загрузился, переход по статье работает. Отдельная Cloudflare CAPTCHA в этой сессии не наблюдалась; это не доказательство прохождения новой проверки на каждом ПК. Тестовая группа не существует, сайт сообщил Group not found. Вход в аккаунт и отправка решений не проверены.
- Из Windows вышли штатно кодом теста. Исходный профиль восстановлен с совпадением SHA-256. Остался только штатный SEB Service; runtime и helper завершены, порт свободен.
- Mac установлен 3.5, подпись и self-test прошли; открыт только организатор. Windows установщик 2.5 собран, но заново целиком не установлен: VM проверяла обновлённые app/helper/hub поверх прежней установки.

Сборка для дальнейшей проверки. Готовность к олимпиаде не подтверждена из-за Cloudflare на Mac и отсутствия проверки авторизации/отправки.
