Установленная production-версия открыла форму организатора и обе стадии запуска. Runtime обнаружил виртуальную машину и штатно отказал: `Virtual Machine Detected`. Production-профиль запрещает VM; его не меняли.

Мышь через инструмент управления возвращала `noWindowsAvailable`; клавиатурой удалось начать запуск. Это ограничение автоматизации не является доказательством ошибки мыши в Roundlane.

После отказа Runtime завершился. Удалена единственная созданная для этой проверки задача планировщика. Процессов экзамена нет, служба установленного Roundlane работает по прежнему пути. VM отправлена на штатное выключение.
