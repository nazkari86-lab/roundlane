# Общие настройки соревнования

Одобренная задача: организатор один раз задаёт группу и код, сохраняет один файл и распространяет его на Mac и Windows. На каждом компьютере достаточно открыть файл через «Открыть настройки»; начало экзамена по-прежнему требует отдельного подтверждения.

Формат `.roundlane`: JSON с четырьмя полями `format=roundlane-competition`, `version=1`, `groupURL`, `quitPasswordHash` (SHA-256, 64 шестнадцатеричных символа). Открытый код не сохраняется. Один файл совместим с обеими платформами. Проверяются схема, версия, размер до 64 КиБ, разрешённая ссылка и хеш; произвольные параметры SEB не принимаются.

В ручном режиме остаются группа и видимый код организатора. Кнопка «Сохранить настройки» проверяет их и открывает системный диалог сохранения. После импорта группа и код защищены от редактирования, вместо кода отображается «У организатора», генерация/копирование кода недоступны. Подтверждение импортированного соревнования не показывает пароль. Повторное открытие другого файла заменяет настройки только после успешной проверки. Настройки не запускают экзамен автоматически и не добавляются в автозапуск.

SEB принимает сохранённый хеш прямо в `hashedQuitPassword`; выход проверяется тем же кодом, который задал организатор. Файл не содержит пароль администратора ОС и не снимает необходимость первоначальной установки SEB администратором Windows.

Границы: файл не подписан и не подтверждает подлинность настроек. Короткий код можно подобрать по хешу; отсутствие открытого кода не является защитой от перебора. Организатор хранит код отдельно и распространяет проверенный файл. Ввод кода на компьютерах после соревнования остаётся ручным; серверная команда выхода в задачу не входит.

Проверка: общий тестовый файл на обеих платформах; экспорт/импорт, совпадение хеша в профиле, отсутствие открытого кода в файле/подтверждении, отказ неверным версиям/ссылкам/хешам/лишним полям/большим файлам, отмена диалогов. Проверка подготовки профиля без блокировки Mac; Windows — форма в VM и точные установленные файлы. Обновлённый общий ZIP сохраняет предыдущую версию.

## Наблюдаемые результаты 10 октября 2026

- Mac 3.4 и установленный Windows 2.4 приняли один тестовый файл и отвергли восемь повреждённых вариантов. Хеш кода совпал с `hashedQuitPassword` сформированного профиля.
- Экспорт через системные диалоги обеих платформ дал одинаковые JSON-настройки без открытого кода. Экспорт Mac загружен в форму Windows; экспорт Windows принят декодером и профилем Mac.
- После импорта поля закрыты для редактирования, код скрыт. Подтверждения Mac и Windows показывают «Код выхода у организатора». Escape отменяет запуск. Неверный файл отключает старт, следующий корректный импорт восстанавливает его.
- Форма Mac просмотрена при узкой и широкой ширине, Windows — при обычном размере. Узкий/широкий размер Windows отдельно не подтверждён.
- Безопасная подготовка Mac проверила профиль, хеш выхода, токен локального сервера и очистку; `exam_started=false`. Основная программа, debug dylib и helper собраны для arm64 и x86_64.
- Roundlane 3.4 установлен на этом Mac с сохранением копии 3.3. Проверены строгая подпись ad hoc, self-test, импорт и совпадение исполняемого файла с собранным. Смонтированный готовый DMG прошёл те же проверки подписи, self-test и импорта без запуска экзамена.
- Точный установщик Windows 2.4 установлен в Windows 11 ARM64 VM с уже установленным официальным SEB. Хеши полезной нагрузки совпали с сборкой. После отмены и закрытия нет процесса Roundlane/SEB client, локального слушателя 18765, временной сессии и ключей автозапуска Roundlane; служба SEB работает.

Файлы доказательств перечислены в [машинном отчёте](shared-settings-verification-2026-10-10.json). Тестовая группа `Test123` не является группой олимпиады; файлы в `setup/shared-settings-check` предназначены только для проверки.

В этой версии реальный экзамен не запускался. Полный Mac режим, запуск на Intel, Windows на настоящем x64 ПК и чистая установка всех Windows зависимостей остаются непроверенными. Mac подписан ad hoc без Developer ID/notarization. Исторические отчёты прежних версий не заменяют эти проверки.
