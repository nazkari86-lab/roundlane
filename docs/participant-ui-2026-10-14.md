# Интерфейс участника — 14 октября 2026

В обычном запуске Mac «Проверить сайты» скрыта и исключена из переходов клавишей Tab. Обработчик не запускает проверку при скрытой или отключённой кнопке. После импорта competition.roundlane кнопка также скрыта. Проверка доступна в отдельном запуске организатора с --organizer-tools; параметр передаётся в дочерний процесс формы. В Windows кнопки проверки сайтов нет.

Для проверки формы запускать --organizer-ui --preflight-only: экзамен не может начаться. Организатор: open -n /Applications/Roundlane.app --args --organizer-tools.
