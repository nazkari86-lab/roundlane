Дерево официального тега 3.3.2 не содержит libSEBSupport.a; у релиза только release notes как отдельный asset. Публичный бесплатный путь к Mac библиотеке не найден. Это не исключает индивидуальную договорённость: подготовленный запрос не отправлен.

Windows DLL получена из официальной установки и проверена отдельно, но разрешение на её распространение и совместимость с Roundlane не установлены. Она не включена в выпуск.

## Реализовано независимо, Windows

Перед готовностью и запуском организатор проверяет Ed25519 подпись точных байтов manifest.json. Публичный ключ закреплён в core/runtime_key.go. После подписи проверяются SHA256 всех перечисленных компонентов и обязательные Runtime/Client/Service/Recovery/Chromium. Неизвестные файлы и ссылки внутри runtime отвергаются. Пустая, чужая, отсутствующая подпись блокирует старт, без перехода к ослабленной проверке.

Закрытый seed хранится отдельно в organizer-private с правами 0600; в установщик и исходники участника не включается. Для собственной сборки используйте ROUNDLANE_SIGNING_KEY и собственный публичный ключ. Это отдельная идентичность Roundlane, не подпись ETH и не официальный Browser Exam Key.

## Границы защиты

Это проверка файлов перед запуском через организаторскую форму, а не монитор памяти процесса и не защита от администратора ОС. Замена самой формы или прямой запуск Runtime обходят эту новую проверку. Подпись не является доверенной Authenticode подписью Windows. Между проверкой и загрузкой остаётся окно изменения файла; установка в Program Files ограничивает доступ обычного участника, но не администратора. Неизвестные файлы могут потребовать очистки старой установки перед обновлением.

Публичные блокировка рабочего стола, клавиатуры, монитор процессов, URL фильтр, собственная служба и восстановление уже встроены. Публичные детекторы RDP и VM доступны в исходниках. Закрытый модуль проверки памяти, фирменные SEB ключи и Apple управляемые возможности не воспроизведены. Mac в этом обновлении не менялся.

## Проверка

Go core tests проверяют нормальные файлы, повреждение executable, замену manifest с пересчитанным хешем, неизвестную DLL, чужую/отсутствующую подпись и подписанный путь вне каталога. Windows проверяется через установленную форму --check-runtime, без kiosk. Результат сохраняется в setup/seb-module-research/windows-signature-results.json.

Наблюдение Windows VM: valid и restored вернули exit 0; tampered-manifest, missing-signature, injected-dll — exit 1 с конкретной ошибкой. Во всех пяти случаях exam_started=false. Проверка не требует внешнего SEB. Проверены точные runtime файлы на хосте командой go run ./cmd/verify-runtime dist; все хеши и подпись прошли. Полный защищённый сеанс с этим обновлением заново не запускался.
