# Roundlane

Экзаменационное приложение для олимпиад по спортивному программированию: выбранный контест Codeforces, C++ компилятор, вкладки и выход по коду организатора. Содержит собственные изменения публичных компонентов Safe Exam Browser; отдельная установка SEB не требуется.

## Скачать

- [macOS — Roundlane-Mac-Tabs.dmg](https://github.com/nazkari86-lab/roundlane/releases/latest/download/Roundlane-Mac-Tabs.dmg)
- [Windows — Roundlane-Windows-Tabs.exe](https://github.com/nazkari86-lab/roundlane/releases/latest/download/Roundlane-Windows-Tabs.exe)

Mac: macOS 12.1+, Apple Silicon и Intel. Windows: обновлённый самостоятельный runtime, Windows 10/11 x64. Файлы выдаются отдельно, без общего ZIP.

Mac: перетащите Roundlane в Applications. Пакет подписан ad hoc, без Developer ID и notarization. Windows: установщик включает runtime, службу восстановления и необходимые зависимости; для установки службы нужен администратор.

## C++ IDE

[OnlineGDB](docs/onlinegdb-2026-10-16.md): C++20 по умолчанию, выбор C++23/26, запуск, отладчик, несколько файлов, тестовый ввод и интерактивная консоль. Проект сохраняется локально между закрытиями вкладок и перезапусками. Нужен интернет.

## Режим участника

Пакеты содержат подписанные настройки подготовленного тестового контеста. При запуске приложение открывает соревнование без стартовой панели. После перезагрузки ОС автоматический запуск не устанавливается. Пароль выхода хранится отдельно у организатора; в настройках находится только хеш и подпись. Ручные настройки установленного пакета участника требуют действующего кода организатора.

Выход: Cmd+Q на Mac, Ctrl+Q на Windows, затем код организатора.

## Исправления и проверки

[Раздельное восстановление кода и тестового ввода](docs/improvements-2026-10-16.md). Автоматические проверки компонентов выполняются в GitHub Actions.

Сохранение проектов OnlineGDB и исходника с тестовым вводом Codeforces; восстановление закрытых вкладок и вкладок после перезапуска; захват последних изменений при закрытии; приоритет актуальных настроек; отклонение некорректных параметров запуска до начала экзамена. На Mac закрытие вкладки — Cmd+W; Ctrl+W остаётся доступным для редактирования текста.

Подтверждены обе архитектуры Mac, целостность DMG, безопасная проверка запуска и восстановление черновика в тестовом WebView. Windows runtime собран в Windows ARM64 VM; проверены все 344 компонента внутри EXE. OnlineGDB проверен в безопасном Mac WebView с фильтром: ввод `7 35` → `42`, запуск/остановка GDB, второй файл. Реальные сетевые проверки Codeforces предыдущего выпуска включали Accepted и запуск теста.

Полная репетиция блокировки на отдельном Mac и обычном Windows x64 нужна перед олимпиадой. Эквивалентность защиты официальному SEB не заявляется.
