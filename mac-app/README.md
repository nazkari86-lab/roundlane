# Roundlane 2.2 — Mac launcher

Для Intel и Apple Silicon. Это универсальное приложение создаёт временный профиль и запускает отдельно установленный Safe Exam Browser. Mac 3.2 со встроенным SEB находится в `native-mac/` и устанавливается на Apple Silicon.

Форма содержит группу, видимый код выхода, «Новый код», «Копировать», состояние готовности и «Начать соревнование». Пустая/неверная группа и неверный код не позволяют начать. Enter в поле не запускает экзамен. Подтверждение показывает группу, код и Cmd+Q; «Назад» или Escape возвращает к форме.

Исходный код выхода — **1234**. Новый код — четыре цифры. Последняя успешно запущенная группа сохраняется; код не сохраняется. Автозапуск не добавляется. Проверка установки SEB и профиля выполняется автоматически.

Сборка: `./build.sh`. Создаёт universal bundle, DMG и ZIP в `dist/`; выполняет self-test, проверку подписи и DMG. `--self-test` и `--diagnostics` доступны для технической проверки. `--preflight-only` показывает форму с отключённым стартом. Скрипт сборки не устанавливает и не запускает экзамен.
