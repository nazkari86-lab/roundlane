# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

- Организатор спортивного программирования настраивает отдельный Mac или Windows компьютер перед соревнованием.
- Участник внутри Safe Exam Browser открывает Codeforces и C++ компилятор через локальную стартовую страницу.

## Product Purpose

Подготовить компьютер к соревнованию с понятным запуском, доступом к нужным ресурсам и всегда доступным выходом по известному организатору коду.

## Positioning

Один локально устанавливаемый комплект для Mac и Windows создаёт временный профиль SEB из ссылки на группу Codeforces и показывает участнику минимальную стартовую страницу для спортивного программирования.

## Operating Context

- Приложение устанавливается на каждый компьютер отдельно. Централизованный запуск не нужен.
- Mac 3.2 содержит публичный SEB classic runtime. Windows 2.2 требует отдельно установленный SEB.
- Организатор вставляет ссылку на группу Codeforces, выбирает код выхода и вручную запускает SEB.
- Участнику нужна ссылка на группу, доступ ко всему Codeforces из неё и C++ компилятор.
- Профиль SEB временный; автозапуска после перезагрузки нет.

## Capabilities and Constraints

- На обоих платформах должен быть понятный выход: Cmd+Q на Mac, Ctrl+Q на Windows или кнопка SEB.
- Код выхода по умолчанию 1234; он должен показываться до запуска и не сохраняться как пароль в настройках приложения.
- История пользователя включает трудное восстановление после блокировки SEB. Нельзя скрывать путь выхода или запускать SEB автоматически при открытии приложения.
- Разрешён весь Codeforces, а не только отдельный контест. Стартовая страница получает ссылку на группу от организатора.
- C++ шаблон использует явные стандартные заголовки, `using namespace std`, быстрый ввод/вывод и не содержит лишнего вывода.
- Стартовая страница должна быть минимальной: только ссылки на группу и компилятор. Без карточек, советов и отдельной кнопки на главную Codeforces.
- Данные о конкретной группе, времени соревнования и аккаунтах участников пока не заданы.

## Brand Commitments

- Название Roundlane. Имя пользователя не используется в названии, иконке, установщиках и интерфейсе.
- Минимальный интерфейс с двумя ссылками. Организатор назначает короткий код, копирует его и запускает соревнование после отдельного подтверждения.
- Иконка — геометрическая буква R. SVG, без генеративных изображений.

## Evidence on Hand

- Исходники Mac и Windows приложений, шаблон SEB, локальная стартовая страница и C++ шаблон находятся в этом каталоге.
- Mac версия проходит встроенный self-test. Windows 2.1 проверен в Windows ARM64 VM с официальным SEB; Windows 2.2 меняет форму организатора. Реальный x64 ПК ещё не проверен.
- Пробный SEB на Mac остановился на списке запрещённых приложений из-за работающего Codex; загрузка Codeforces и компилятора внутри SEB пока не подтверждена.

## Product Principles

1. На стартовой странице остаются только два необходимых перехода.
2. Организатор видит ссылку, код выхода и состояние готовности до запуска.
3. Ошибку в шаблоне или настройке нужно обнаружить до экзаменационного режима.
4. Новая версия должна сохранять понятный путь выхода на обеих платформах.
